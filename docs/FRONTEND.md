# Frontend Architecture — Web (TanStack Start) + Mobile (Expo) + UI

Modern, fully-wired frontends that share contracts + i18n + api-client with the modular monolith backend. No drift, no duplicate schemas, single design token system.

## System Map

- `packages/ui` — Base UI + shadcn base-nova + Tailwind 4 design system. Web consumes via `import { Button } from '@repo/ui/components/button'` + `import '@repo/ui/globals.css'`. Mobile mirrors tokens via `apps/mobile/tailwind.config.js` (NativeWind) and never imports DOM primitives.
- `packages/contracts` — Zod schemas + oRPC contracts + pagination constants. Used by api (`ZodValidationPipe`), web and mobile (`react-hook-form` + `zodResolver`, `getApiClient`).
- `packages/api-client` — `createApiClient(baseUrl, { getAccessToken, getLocale, getTenantId, onAuthRefreshed, onAuthFailure })` with `RPCLink` + `createORPCClient` + `createTanstackQueryUtils`, auto `idempotency-key`, 401 `requestRefresh`.
- `packages/i18n` — `en.json`/`es.json`/`fr.json` + `locales` + `DEFAULT_LOCALE`. Backend `I18nService.t()`, frontend `react-i18next` `useTranslation().t()`.

## Web — `apps/web` (TanStack Start 1)

**Stack:** Vite 8 + TanStack Start 1 (streaming SSR, server functions, `tanstackStart()` Vite plugin) + TanStack Router 1 file-based + TanStack Query 5 + Zustand 5 (persist localStorage) + react-i18next + Tailwind 4 + shadcn base-nova + Base UI React 1 + lucide + react-hook-form + zod.

### Quick Start

```bash
pnpm --filter web dev          # http://localhost:5173 (Vite dev + Start SSR)
pnpm --filter web build        # vite build -> .output/server/index.mjs
pnpm --filter web start        # node .output/server/index.mjs (Nitro)
pnpm dlx shadcn@latest add card -c apps/web   # add primitive to packages/ui
```

### Structure

```
apps/web/
  vite.config.ts               # tanstackStart({ srcDirectory: 'src' }) + viteReact() + tailwindcss() + tsConfigPaths()
  components.json              # style base-nova, RSC true, Tailwind 4, css ../../packages/ui/src/styles/globals.css, aliases @/* + @repo/ui
  tsconfig.app.json / tsconfig.node.json
  src/
    router.tsx                 # createRouter({ routeTree, context: { queryClient } }) + setupRouterSsrQueryIntegration
    routeTree.gen.ts           # generated by @tanstack/router-plugin — do not hand-edit
    routes/__root.tsx          # <html> + HeadContent + Scripts + ThemeProvider + QueryProvider + I18nProvider + Toaster; imports '@repo/ui/globals.css'
    routes/index.tsx           # landing (Badge + Card + Button + lucide, i18n)
    routes/auth.tsx            # Tabs login/register (useForm zodResolver LoginSchema/RegisterSchema + useMutation + getApiClient + setAuth + navigate)
    routes/dashboard.tsx       # protected (useAuthStore; useQuery notes + redirect to /auth if unauthenticated)
    routes/notes.tsx           # vertical slice (useQuery + useMutation + invalidation + Flat form + delete)
    components/theme-provider.tsx # light/dark/system + localStorage + matchMedia + 'd' toggle

    lib/api.ts                 # getApiClient() singleton wiring Zustand + 401 refresh
    lib/i18n.tsx               # react-i18next init with @repo/i18n resources + LanguageDetector
    lib/query-client.tsx        # QueryClient + QueryProvider

    stores/tenant.store.ts
    hooks/use-auth.ts
    features/notes/notes.queries.ts
    features/auth/auth.mutations.ts
```

### Key Patterns

- **Routes:** `createFileRoute('/path')({ component })` — file path dictates URL. Add `src/routes/invoices.tsx` + query helper, done.
- **Contracts:** `useForm({ resolver: zodResolver(CreateNoteSchema) })` where schema imported from `@repo/contracts`.
- **API:** `const client = getApiClient(); const res = await client.notes.list({ page, limit }); if(res.status!==200) throw`. For type-safe RPC: `const orpc = getApiClient().orpc` etc via `createTanstackQueryUtils`.
- **Tenant:** `useTenantStore.setTenantId(id)` — all subsequent calls auto-send `x-tenant-id`.
- **i18n:** `const { t } = useTranslation(); t('notes.createNote')`.
- **UI:** `import { Button } from '@repo/ui/components/button'` + `Card` etc. Use `cn()` for merges. Theme via `useTheme()` + `<ThemeProvider>`.

### Env

```
VITE_API_URL=http://localhost:3000/api   # api prefix (app/api/src/main.ts has setGlobalPrefix('api'))
VITE_APP_NAME=Workspace
```

Validated in `src/lib/env.ts`. Never raw `process.env` elsewhere. Production: inject via hosting env or `.env`.

### Shadcn + Base UI

Per https://ui.shadcn.com/docs/installation/tanstack and https://base-ui.com/react/overview/quick-start :

- `pnpm dlx shadcn@latest add <component> -c apps/web` writes to `packages/ui/src/components/<component>.tsx`. The component is a Base UI primitive (`import { Button as ButtonPrimitive } from '@base-ui/react/button'` + `cva`).
- `globals.css` uses `@import "tailwindcss"; @import "tw-animate-css"; @import "shadcn/tailwind.css";` + CSS variables + `@source` for `apps/web` + `packages/ui`.
- On web, portaling components (Dialog, Popover) need `body { position: relative }` + `isolation: isolate` on root (handled in globals).

## Mobile — `apps/mobile` (Expo SDK 53 + expo-router)

**Stack:** Expo SDK 53 + expo-router 5 (file-based `app/`) + NativeWind 4 (Tailwind on RN) + tailwindcss 3.4 + Zustand 5 (expo-secure-store) + react-i18next + TanStack Query 5.

### Quick Start

```bash
pnpm --filter mobile dev         # expo start -> Metro 8081 QR (press a/i/w)
pnpm --filter mobile android     # expo run:android
pnpm --filter mobile ios         # expo run:ios
pnpm --filter mobile build       # expo export -> dist/
```

### Structure

```
apps/mobile/
  app.json                     # name/slug/scheme modular-monolith, plugins expo-router + expo-secure-store, typedRoutes
  metro.config.js              # withNativeWind({ input: './global.css' }) + watchFolders=[workspaceRoot]
  tailwind.config.js           # preset nativewind/preset, content app/** + src/**, mirrored colors
  global.css                   # @tailwind base/components/utilities
  babel.config.js              # babel-preset-expo + nativewind/babel + expo-router/babel + reanimated
  tsconfig.json                # extends expo/tsconfig.base, paths @/*
  app/_layout.tsx              # initI18n() + QueryClientProvider + Stack
  app/index.tsx                # landing (View/Text/Pressable + Link)
  app/auth.tsx                 # login/register + getApiClient + SecureStore
  app/notes.tsx                # notes (FlatList + NativeWind)
  app/(tabs)/_layout.tsx       # Tabs
  app/(tabs)/index.tsx         # dashboard
  app/(tabs)/settings.tsx      # locale switch + logout
  src/lib/env.ts              # EXPO_PUBLIC_API_URL (expo-constants + process.env)
  src/lib/api.ts               # getApiClient(EXPO_PUBLIC_API_URL, SecureStore)
  src/lib/i18n.ts              # initI18n resources @repo/i18n
  src/stores/auth.store.ts     # persist SecureStore
  src/stores/locale.store.ts
  src/stores/tenant.store.ts
```

### Key Patterns

- **Routing:** `app/auth.tsx` => `/auth`, `app/(tabs)/settings.tsx` => `/(tabs)/settings`. Navigate via `Link href="/notes"` or `router.replace('/(tabs)')`.
- **Styling:** `className` via NativeWind (`className="bg-primary rounded-lg p-4"`). Tokens must stay in sync with `packages/ui/src/styles/globals.css` — manually mirror CSS variables into `tailwind.config.js` `theme.extend.colors`.
- **SecureStore:** `zustand` persist adapter wraps `SecureStore.getItemAsync/setItemAsync/deleteItemAsync`. Never use AsyncStorage for tokens.
- **i18n:** same keys as web, `useTranslation()`.

## Troubleshooting

- **Metro can't resolve `@repo/*`:** check `metro.config.js` watchFolders + resolver.nodeModulesPaths + `EXPO_NO_METRO_WORKSPACE_ROOT` (SDK52+ auto workspace root). Keep `disableHierarchicalLookup=false`? Our config sets `true` — if fails, toggle.
- **NativeWind not styling:** ensure `global.css` is imported in `app/_layout.tsx`, `babel.config.js` has `nativewind/babel` before others, and `tailwind.config.js` content includes `app/**`.
- **Web routeTree not updating:** `vite dev` regenerates `src/routeTree.gen.ts` — commit it so `pnpm typecheck` passes in CI without Vite running.
- **`@repo/ui` not found in web:** check `apps/web/tsconfig.app.json` paths `@repo/ui/*` + `vite-tsconfig-paths` plugin + `pnpm-workspace.yaml` includes `packages/*`.
- **Shadcn RTL styles:** `components.json` has `rtl: true`; ensure `direction` component wraps app if needed (from `@repo/ui/components/direction`).
